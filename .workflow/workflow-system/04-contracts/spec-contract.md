# Contrat de spécification

~~~yaml
request_id: "REQ-YYYYMMDD-001"
route: "R0|R1|R2|R3|R4|R5"
problem: ""
outcome: ""
scope:
  in: []
  out: []
acceptance_criteria: []
constraints: []
affected_files: []
test_strategy: ""
risks: []
open_questions: []
approved_by_user: false
base_commit: ""
~~~

La spécification est exploitable lorsque le problème, le périmètre, les critères d'acceptation et la stratégie de test sont renseignés. `approved_by_user` doit être `true` avant toute modification.
