# 04 — Contrats d'échange

Ces contrats rendent les handoffs lisibles par Codex, GLM, Claude, Aider ou un LLM local. Ils définissent les entrées, les sorties et les gates ; ils ne remplacent pas les skills natives.

- `spec-contract.md` : ce qui doit être décidé avant de coder ;
- `evidence-bundle.md` : preuves produites par l'implémentation ;
- `review-report.md` : rapport indépendant ;
- `git-gate.md` : règles de branche, commit et intégration.
